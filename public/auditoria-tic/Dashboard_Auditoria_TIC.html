Re-analizar carpeta

Esta acción recorrerá la carpeta de SharePoint en busca de nueva información (nuevos meses, periodos, cursos y asignaturas) y actualizará los datos del dashboard.

El escaneo real requiere un backend con permisos de Microsoft Graph. Configure la URL del endpoint; el dashboard enviará un POST y luego recargará los datos.

¿Cómo funciona el backend?

El backend (Azure Function o Power Automate) usa Microsoft Graph para leer la carpeta, extrae el texto de los documentos, calcula los indicadores por año/periodo/mes/curso/asignatura y guarda el JSON que consume este dashboard. Puede ejecutarse manualmente o con un temporizador mensual.
